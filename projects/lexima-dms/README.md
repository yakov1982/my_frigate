# DIGITAL DOCUMENTS MVP

Упрощённый пример системы документооборота, вдохновлённый типовыми возможностями СЭД/ECM класса «Лексима»: реестр документов, хранение файлов и версий, маршруты согласования, задачи согласующим, журнал аудита.

> Важно: это **не** копия «Лексима» и не использует её исходники/протоколы. Это самостоятельный учебный/стартер‑проект, повторяющий *типовые* сценарии документооборота.

## Что обычно есть в «Лексима»-подобной СЭД (краткий анализ)

- **Карточка документа**: тип, заголовок, регистрационный номер, атрибуты, статус.
- **Регистрация**: присвоение номера, журнал регистрации, контроль обязательных полей.
- **Файлы и версии**: хранение вложений, версионирование, скачивание/просмотр.
- **Маршруты**: согласование по шагам (последовательное/параллельное), визирование, отклонение с комментарием.
- **Задачи и контроль**: «мои задачи» для согласующих, сроки, напоминания (в MVP — без сроков/уведомлений).
- **Роли и права**: автор/согласующий/админ, ограничения на просмотр и действия.
- **Аудит**: кто и когда создал/изменил/согласовал/отклонил.
- **Поиск/фильтры**: по атрибутам и тексту (в MVP — простой поиск по title/number).
- **Интеграции**: почта, сканирование/OCR, ЭП, 1С и т.д. (в MVP не реализовано).

## Что реализовано в этом MVP

- **Backend API**: FastAPI + SQLite.
- **Пользователи**: создание через CLI, логин по JWT.
- **Документы**: создание/список/детали.
- **Файлы**: загрузка файла при создании документа, добавление новых версий, скачивание.
- **Согласование**: последовательная цепочка согласующих, approve/reject, «мои задачи».
- **Аудит**: запись ключевых действий в журнал.

## Структура

```
projects/lexima-dms/   # DIGITAL DOCUMENTS MVP
  backend/
    lexima_dms/        # приложение
    manage.py          # CLI: init-db, create-user
    requirements.txt
```

## Быстрый старт (локально)

```bash
cd projects/lexima-dms/backend
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -U pip
pip install -r requirements.txt

# 1) инициализировать БД
python manage.py init-db

# 2) создать пользователя
python manage.py create-user --username admin --password admin --role admin

# 3) запустить API
uvicorn lexima_dms.api.main:app --reload --port 8080
```

Swagger откроется на `http://localhost:8080/docs`.

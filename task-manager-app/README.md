# 📝 Менеджер Задач

Современное веб-приложение для управления задачами с красивым и интуитивным интерфейсом.

![Task Manager](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## 🌟 Особенности

- ✨ Современный и отзывчивый дизайн
- 📱 Полностью адаптивный интерфейс для мобильных устройств
- 💾 Автоматическое сохранение задач в localStorage
- 🎯 Фильтрация задач (все, активные, завершённые)
- ⚡ Быстрая и плавная анимация
- 📊 Статистика задач в реальном времени
- 🎨 Градиентный дизайн с приятными цветами

## 🚀 Быстрый старт

### Просто откройте файл

Просто откройте `index.html` в вашем любимом браузере!

### Используя локальный сервер

```bash
# Клонируйте репозиторий
git clone <repository-url>

# Перейдите в директорию проекта
cd task-manager-app

# Запустите локальный сервер (используя http-server)
npm start

# Или используя live-server для разработки
npm run dev
```

## 📋 Как использовать

1. **Добавление задачи**: Введите текст в поле ввода и нажмите "Добавить" или Enter
2. **Отметка задачи**: Кликните на чекбокс слева от задачи, чтобы отметить её как завершённую
3. **Удаление задачи**: Нажмите кнопку "Удалить" справа от задачи
4. **Фильтрация**: Используйте вкладки для переключения между всеми, активными и завершёнными задачами

## 🛠️ Технологии

- **HTML5** - разметка
- **CSS3** - стилизация с современными возможностями (Grid, Flexbox, анимации)
- **Vanilla JavaScript (ES6+)** - функциональность без использования фреймворков
- **LocalStorage API** - для хранения данных
